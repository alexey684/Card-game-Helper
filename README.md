# Оверлей-помощник для «Дурака» (mail.ru)

Десктопное приложение, которое в реальном времени отслеживает вышедшие карты и ведёт таблицу всех 36 карт, помогая принимать решения в партии.

## Как работает

На экране отображается таблица из 36 карт. Управление — глобальными хоткеями:

| Клавиша | Действие | Визуал в таблице |
|---------|----------|------------------|
| `Space` | Карты на столе ушли в отбой | Ячейки закрашиваются сплошным |
| `←` / `→` | Карта ушла сопернику слева / справа | Полупрозрачный синий / зелёный |
| `R` | Сброс партии | Все 36 карт снова видны |

## Ключевая особенность

Вместо нестабильного распознавания цифр (OCR) реализован **точный маппинг экранных координат**: вручную составлена карта пикселей для всех **36 карт в 12 позициях** на столе. Это обеспечивает **100% надёжность** определения карты без ошибок распознавания.
